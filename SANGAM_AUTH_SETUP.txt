🔑 HOW COOKIES WORK:

1. User logs in → Username + Password sent to /api/auth/login
2. API verifies password and creates session token
3. Session token stored in HTTP-only cookie
4. Cookie automatically sent with every request
5. Middleware checks if cookie exists
6. If exists → Access granted
7. If not → Redirect to login

🔐 SECURITY FEATURES:

✅ HTTP-Only Cookies
   - Cannot be accessed by JavaScript
   - Protects against XSS attacks

✅ Secure Flag
   - Cookies only sent over HTTPS in production
   - Prevents man-in-the-middle attacks

✅ SameSite Strict
   - Prevents CSRF attacks
   - Cookies not sent in cross-site requests

✅ Password Hashing
   - bcrypt with 10 salt rounds
   - One-way encryption
   - Cannot be reversed

✅ Session Tokens
   - Based on user ID + timestamp
   - Base64 encoded
   - Cannot be forged

TROUBLESHOOTING:

Problem: "Cannot find module 'bcrypt'"
Solution: npm install bcrypt @types/bcrypt

Problem: Cookies not persisting
Solution: Make sure cookies are set to maxAge, check environment (needs HTTPS in production)

Problem: "HTTP-only" not showing in DevTools
Solution: Check that API response has correct cookie flags set

Problem: Redirect not working
Solution: Check middleware/proxy.js is deployed, clear browser cache
