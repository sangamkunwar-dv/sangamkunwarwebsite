==========================================
MONGODB SETUP - QUICK REFERENCE
==========================================

WHAT YOU NEED TO DO (10 MINUTES):

1. CREATE ACCOUNT
   Go to: https://www.mongodb.com/cloud/atlas
   Sign up → Create account

2. CREATE CLUSTER
   Click "Create a Deployment"
   Choose M0 (FREE tier)
   Wait 3-5 minutes

3. CREATE DATABASE
   Name: portfolio
   Collections:
   - projects
   - hero_settings
   - skills

4. GET CONNECTION STRING
   Click "Connect" → "Drivers" → Copy URL
   Format: mongodb+srv://user:pass@cluster...

5. REPLACE CREDENTIALS
   Username: your_username
   Password: your_password
   Example: 
   mongodb+srv://portfolio:MyPassword123@my-cluster.mongodb.net/portfolio?retryWrites=true&w=majority

6. ADD TO NETLIFY
   Site Settings → Build & deploy → Environment
   Add: MONGODB_URI = [paste connection string]

7. REDEPLOY
   Netlify → Deployments → Trigger deploy

8. TEST
   Admin → Add project → Save
   Check MongoDB Atlas to see data
   Website → Refresh → See new project

==========================================

MONGODB CONNECTION STRING PARTS:
mongodb+srv://   <- Protocol
username:        <- MongoDB user
password@        <- MongoDB password
cluster.mdb...   <- Cluster name
/portfolio       <- Database name

==========================================

TROUBLESHOOTING:

Issue: "MONGODB_URI not found"
Fix: Add to Netlify env vars and redeploy

Issue: "Connection refused"
Fix: Add your IP to MongoDB whitelist

Issue: "Auth failed"
Fix: Check username/password in connection string

Issue: "Database doesn't exist"
Fix: Create database named "portfolio" in MongoDB
