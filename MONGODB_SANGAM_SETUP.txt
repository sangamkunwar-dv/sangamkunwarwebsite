PROBLEM: MongoDB connection not established yet
SOLUTION: 4 simple steps below

═══════════════════════════════════════════════════════════

STEP 1: CREATE FREE MONGODB ATLAS ACCOUNT
─────────────────────────────────────────

1. Go to: https://www.mongodb.com/cloud/atlas
2. Click "Sign Up" button
3. Create account with:
   - Email: your email
   - Password: strong password
   - Name: Your name
4. Click "Sign Up"

═══════════════════════════════════════════════════════════

STEP 2: CREATE A CLUSTER
──────────────────────

1. After signup, you'll see "Create a deployment" 
2. Choose: M0 (FREE)
3. Cloud Provider: AWS
4. Region: Pick closest to you (US, EU, etc.)
5. Cluster Name: "sangam-portfolio"
6. Click "Create Deployment"
7. WAIT 3-5 minutes for cluster to create

═══════════════════════════════════════════════════════════

STEP 3: GET CONNECTION STRING
────────────────────────────

1. When cluster is ready, click "Connect"
2. You'll see 3 options - choose "Drivers"
3. Select: 
   - Driver: Node.js
   - Version: 5.9 or later
4. Copy the connection string
   It will look like:
   mongodb+srv://<username>:<password>@sangam-portfolio.xxxxx.mongodb.net/?retryWrites=true&w=majority

5. Replace:
   - <username> with: "admin"
   - <password> with: YOUR PASSWORD (you set it)
   - Change the path to: /portfolio?retryWrites=true&w=majority

Final string should look like:
mongodb+srv://admin:yourpassword123@sangam-portfolio.xxxxx.mongodb.net/portfolio?retryWrites=true&w=majority

═══════════════════════════════════════════════════════════

STEP 4: ADD CONNECTION STRING TO NETLIFY
───────────────────────────────────────────

1. Go to Netlify: https://app.netlify.com
2. Click your site "sangamtest1"
3. Go to: Site settings → Build & deploy → Environment
4. Click "Edit variables"
5. Add new variable:
   - Key: MONGODB_URI
   - Value: [paste your connection string from Step 3]
6. Click "Save"

═══════════════════════════════════════════════════════════

STEP 5: REDEPLOY YOUR SITE
──────────────────────────

1. Go to Netlify Deployments
2. Click "Trigger deploy"
3. Wait for deployment to complete

═══════════════════════════════════════════════════════════

STEP 6: CREATE MONGODB COLLECTIONS
──────────────────────────────────

1. Go back to MongoDB Atlas
2. Click "Browse Collections"
3. Click "Create Collection"
4. Database: "portfolio"
5. Collection: "projects"
6. Create it

7. Repeat for other collections:
   - "hero_settings"
   - "skills"

═══════════════════════════════════════════════════════════

STEP 7: TEST EVERYTHING
──────────────────────

1. Go to: https://sangamtest1.netlify.app
2. Go to /admin
3. Try adding a project
4. Click "Save Project"
5. Should say "Project saved successfully!"
6. Go back to website home page
7. You should see your project!

═══════════════════════════════════════════════════════════

TROUBLESHOOTING:

If you see "Error updating hero content":
- Make sure MONGODB_URI is set correctly
- Check that password doesn't have special characters (use simple password)
- Wait 2-3 minutes after deployment

If projects not showing:
- Make sure collections exist in MongoDB
- Try adding a test project from admin panel
- Check browser console (F12) for errors

If nothing works:
- Go to MongoDB Atlas
- Click "Restart project" (Settings)
- Redeploy on Netlify
