===============================================
  HOW TO CREATE MONGODB USERNAME & PASSWORD
===============================================

COMPLETE STEP-BY-STEP GUIDE FOR SANGAM

===============================================
STEP 1: CREATE MONGODB ATLAS ACCOUNT (FREE)
===============================================

1. Go to: https://www.mongodb.com/cloud/atlas
2. Click "Sign Up" (top right)
3. Choose "Sign up with Email"
4. Fill in:
   - Email: your-email@gmail.com
   - Password: strong-password (remember this!)
   - First Name: Sangam
   - Last Name: Kunwar
5. Click "Create account"
6. Verify your email (check inbox)
7. Login to MongoDB Atlas

===============================================
STEP 2: CREATE A NEW PROJECT
===============================================

1. After login, click "Create" button
2. Name your project: "Portfolio"
3. Click "Create Project"
4. Click "Build a Database"

===============================================
STEP 3: CHOOSE FREE TIER
===============================================

1. Select "Shared" (FREE tier)
2. Click "Create" button
3. Choose region closest to you:
   - If in India: Select "Mumbai" or "Singapore"
   - If in USA: Select "us-east-1"
4. Click "Create Cluster"
5. Wait 2-5 minutes for cluster to be created

===============================================
STEP 4: CREATE DATABASE USERNAME & PASSWORD
===============================================

IMPORTANT: This is your login credentials for the database!

Method 1: During Cluster Setup (Easiest)
-----------------------------------------

1. When cluster is being created, you'll see a popup
2. Fill in:
   
   Username: sangamadmin
   Password: (Click "Generate Secure Password" OR type your own)
   
   Example strong password:
   - SangamPortfolio@2024
   - MongoDBPass123!
   - Portfolio#Sangam2024
   
3. Copy the password somewhere safe (write it down!)
4. Click "Create User"

Method 2: Create User Later (If you missed the popup)
-----------------------------------------------------

1. Go to: MongoDB Atlas Dashboard
2. Click your project name
3. On left side, click "Database Access"
4. Click "Add New Database User"
5. Fill in:
   
   Username: sangamadmin
   Password: (Click "Generate" or type your own)
   
6. For "Built-in Role" select: "Atlas Admin"
7. Click "Add User"
8. Copy your credentials!

===============================================
STEP 5: GET YOUR CONNECTION STRING
===============================================

1. Go to: MongoDB Atlas Dashboard
2. Click "Clusters" (left sidebar)
3. Find your cluster, click "Connect"
4. Click "Drivers"
5. Choose "Node.js" from dropdown
6. Copy the connection string

It will look like:
mongodb+srv://sangamadmin:PASSWORD@cluster0.xxxxx.mongodb.net/portfolio?retryWrites=true&w=majority

Replace:
- "sangamadmin" with your username
- "PASSWORD" with your actual password
- "cluster0" stays the same
- "portfolio" is your database name

===============================================
STEP 6: SAVE YOUR CREDENTIALS
===============================================

Create a safe file and save:

USERNAME: sangamadmin
PASSWORD: YourStrongPassword123!
CONNECTION STRING: 
mongodb+srv://sangamadmin:YourStrongPassword123!@cluster0.xxxxx.mongodb.net/portfolio?retryWrites=true&w=majority

DATABASE NAME: portfolio
COLLECTIONS: projects, hero_settings, skills

===============================================
STEP 7: CREATE COLLECTIONS (OPTIONAL)
===============================================

MongoDB creates collections automatically when you insert data.
But you can pre-create them:

1. Go to "Databases" tab
2. Click your cluster
3. Click "Collections"
4. Click "Create Collection"
5. Create three collections:
   - projects
   - hero_settings
   - skills

===============================================
STEP 8: SET UP IP WHITELIST (IMPORTANT!)
===============================================

Your Netlify IP needs access to MongoDB:

1. Go to "Network Access" (left sidebar)
2. Click "Add IP Address"
3. Click "Allow Access from Anywhere"
   (Or add your Netlify IP: 0.0.0.0/0)
4. Click "Confirm"

===============================================
STEP 9: ADD TO NETLIFY
===============================================

1. Go to your Netlify site: sangamtest1.netlify.app
2. Settings → Build & deploy → Environment
3. Add new variable:

   KEY: MONGODB_URI
   VALUE: [Your connection string from Step 5]

Example:
MONGODB_URI=mongodb+srv://sangamadmin:SangamPortfolio@2024@cluster0.abcdef.mongodb.net/portfolio?retryWrites=true&w=majority

4. Save and redeploy

===============================================
STEP 10: TEST YOUR CONNECTION
===============================================

1. Go to your admin panel
2. Try to add a project
3. Check MongoDB Atlas to see if it saved
4. If you see your data in MongoDB, it works!

===============================================
SECURITY TIPS
===============================================

1. NEVER share your password
2. NEVER put credentials in code (use env vars)
3. Use strong passwords (mix uppercase, numbers, symbols)
4. Change password every 3 months
5. Use IP whitelist for production (limit to Netlify IPs)

===============================================
COMMON ISSUES
===============================================

"Cannot connect to MongoDB"
→ Check your IP whitelist is set to "Allow from Anywhere"
→ Check your password is correct (no special characters issue)

"Wrong password"
→ Copy-paste carefully (no spaces before/after)
→ Regenerate password if unsure

"Connection string not working"
→ Make sure to replace "PASSWORD" with actual password
→ Don't use <> brackets in real string

"Still having issues?"
→ Go to MongoDB Support: https://support.mongodb.com
→ Create a new user and try again
